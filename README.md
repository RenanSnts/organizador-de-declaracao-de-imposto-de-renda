# 💰 Renda Organizer

**Organizador de informações para a Declaração do Imposto de Renda | Excel**

## 📌 Sobre o projeto

O **Renda Organizer** é uma ferramenta desenvolvida no Microsoft Excel com o objetivo de facilitar a organização e a centralização de informações essenciais para a preparação da declaração do Imposto de Renda Pessoa Física (IRPF).

A solução foi projetada para permitir que o usuário registre, consulte e organize seus dados de maneira eficiente, utilizando uma interface amigável, menus de navegação, validações de dados e recursos auxiliares que tornam o processo mais prático e estruturado.

O projeto busca transformar informações que normalmente ficam dispersas em diferentes documentos e registros em uma base organizada, facilitando sua consulta e conferência.

## 🎯 Objetivos do projeto

- Centralizar informações pessoais e dados relevantes para a declaração do Imposto de Renda.
- Organizar informes de rendimentos bancários em um único local.
- Registrar entradas financeiras ao longo do tempo.
- Padronizar o preenchimento por meio de listas e validações de dados.
- Facilitar a navegação entre as diferentes áreas da ferramenta.
- Reduzir erros de preenchimento e melhorar a organização das informações.
- Aplicar recursos do Excel no desenvolvimento de uma solução prática para uma necessidade real.

## ⚙️ Funcionalidades

### 👤 1. Dados do titular

Área destinada ao registro e à consulta das principais informações cadastrais do contribuinte.

- Nome completo e CPF.
- Data de nascimento e título de eleitor.
- Informações sobre cônjuge e dependentes.
- Endereço, CEP e telefones.
- E-mail para contato.
- Registro de informações sobre alterações em relação à entrega anterior.

### 🏦 2. Informes de rendimentos bancários

Área voltada à organização dos dados financeiros fornecidos pelas instituições bancárias.

- Identificação dos bancos.
- Registro dos valores informados.
- Associação dos respectivos documentos e anexos.
- Centralização das informações para facilitar a consulta posterior.

### 📈 3. Notas bancárias e extratos de holerites

Área destinada ao registro de entradas financeiras, permitindo acompanhar os valores recebidos e suas respectivas categorias.

- Registro da data de cada entrada.
- Classificação por categoria, como holerite, freelance e CNPJ.
- Registro dos valores recebidos.
- Organização cronológica das movimentações.

Essa estrutura facilita a consulta dos recebimentos e a conferência dos registros financeiros.

### 📋 4. Tabelas de apoio

Planilha auxiliar utilizada para armazenar listas de referência, como instituições bancárias.

- Padronização das opções de preenchimento.
- Apoio às listas suspensas.
- Redução de inconsistências na entrada de dados.
- Facilidade de manutenção das informações de referência.

## 💡 Diferenciais

- **Centralização:** informações relevantes reunidas em uma única ferramenta.
- **Praticidade:** preenchimento estruturado e navegação simplificada.
- **Padronização:** uso de listas e validações para melhorar a consistência dos dados.

## 🚀 Como utilizar

1. Baixe o arquivo `Renda_Organizer.xlsx` disponível neste repositório.
2. Abra o arquivo no Microsoft Excel.
3. Acesse a aba **TITULAR** e preencha os dados cadastrais.
4. Na aba **INFORMES**, organize os dados dos informes de rendimentos bancários e seus respectivos documentos.
5. Utilize a aba **NOTAS** para registrar as entradas financeiras, informando data, categoria e valor.
6. Consulte a aba **TABELAS** para visualizar as listas de apoio utilizadas pela ferramenta.
7. Revise as informações preenchidas e confira os documentos originais antes de utilizá-las na preparação da declaração.

## 🔒 Privacidade e segurança

Os dados utilizados na ferramenta podem incluir informações pessoais e financeiras sensíveis. Recomenda-se utilizar dados fictícios em demonstrações públicas e remover informações reais antes de publicar o arquivo no GitHub.

O projeto funciona como um organizador de informações e **não substitui o programa oficial da Receita Federal, não transmite declarações e não garante, por si só, a conformidade fiscal dos dados registrados**.
